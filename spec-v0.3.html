💊 血圧モニター Webアプリ 仕様書 v0.3

最終更新: 2026-05-13  |  状態: 草案（検討中）

前版（v0.2）からの変更： 平均血圧 = MAP計算 (SBP+DBP×2)÷3 → 平均血圧 = 月間average（各日のSBP平均 / DBP平均）

1. プロジェクト概要

項目内容
アプリ名血圧モニター（仮称）
対象ユーザー医師・看護師（外来診療の日常業務）
動作環境
  • OS: Windows 10 / CPU: Intel Core i5-10500 / RAM: 8GB
  • ネットワーク: オフライン
  • 権限: 一般ユーザー（管理者権限なし）
  • データ転送: USBメモリ経由
実行方式ブラウザでローカルHTMLファイルを開く（file://）
技術制約CDN不可、インストール不可 → ブラウザ標準機能のみ（IndexedDB + Canvas 2D）

2. 機能要件

2.1 患者管理（IDベース）

各患者に固有のID（P001〜P999）を割り当て、ID入力で即座に患者ページを表示。

項目型規則備考
患者ID文字列P + 3桁数字新規登録時は自動採番
患者氏名文字列全角1〜20文字氏名は表示用のみ
性別選択男 / 女任意
生年月日日付YYYY-MM-DD任意

操作フロー: ID入力欄にID入力 or 既存ID選択 → 患者ページ（血圧入力＋グラフ）へ遷移

2.2 血圧データ入力（日次）

入力項目型範囲備考
測定日日付YYYY-MM-DDデフォルトは本日
収縮期血圧（上）数値50〜300 mmHg必須
拡張期血圧（下）数値30〜200 mmHg必須
メモ文字列全角200文字以内任意

日次入力は収縮期・拡張期の2項目のみ。平均は月間サマリーで自動算出。

2.3 月間サマリー（自動算出）

各月の測定データから以下を自動算出・表示：

項目定義表示
平均収縮期その月の全測定日のSBPの平均値グラフ：水平点線 + 数値
平均拡張期その月の全測定日のDBPの平均値グラフ：水平点線 + 数値
最高収縮期その月の最大SBP（該当日付付き）グラフ：赤点線 + 値と日付
最低収縮期その月の最小SBP（該当日付付き）グラフ：青点線 + 値と日付
最高拡張期その月の最大DBP（該当日付付き）グラフ：赤点線 + 値と日付
最低拡張期その月の最小DBP（該当日付付き）グラフ：青点線 + 値と日付

2.4 折れ線グラフ表示

表示項目内容
X軸日付（時系列）。1ヶ月=31日分
Y軸血圧値（mmHg）。20mmHg刻み
折れ線（日次）赤=収縮期 / 青=拡張期
平均線赤/青の水平点線（月間平均値）
警戒ライン収縮期140mmHg（赤破線）/ 拡張期90mmHg（青破線）
高低値ライン月間最高・最低を水平線で表示
正常範囲帯SBP<120 かつ DBP<80 の帯を薄緑着色
データポイント色分け正常:通常 / 1期高血圧:オレンジ / 2期高血圧:赤枠
ツールチップマウスオーバーで日付・SBP・DBP表示

2.5 データ管理

機能内容
ローカル保存IndexedDB
CSVエクスポート患者 or 全患者の一括出力
CSVインポートCSVから一括取り込み（重複は上書き確認）
JSONバックアップ/復元全データのエクスポート/インポート
患者削除確認ダイアログ付き

4.2 IndexedDB スキーマ


■ Database: "BloodPressureDB" v1

○ patients（患者マスタ）
  keyPath: "id" (string) 例: "P001"
  { id, name, gender, birthDate, memo, createdAt }

○ readings（測定データ）
  keyPath: "id" (auto-increment)
  インデックス:
    "byPatient"     → patientId
    "byPatientDate" → [patientId, date] (一意制約)
    "byDate"        → date
  { id, patientId, date, systolic, diastolic, note, createdAt, updatedAt }
