# 💊 血圧モニター

**オフライン専用**の血圧管理Webアプリ。USBメモリで持ち運び、ブラウザだけで動作します。

## 動作環境

| 項目 | 条件 |
|------|------|
| OS | Windows 10 |
| ブラウザ | Chrome 90+ / Edge 90+ / Firefox 88+ |
| ネットワーク | **不要（オフライン動作）** |
| 管理者権限 | 不要 |
| インストール | 不要（ブラウザでHTMLファイルを開くだけ） |

## クイックスタート

### 方法1：単一HTMLファイル（推奨・USB配布向け）

1. **`bp-app.html`** をUSBメモリにコピー
2. 電子カルテ端末で `bp-app.html` をダブルクリック
3. Chrome / Edge で開く
4. 患者IDを入力 → Enter → 使い始める

### 方法2：開発用（モジュール分割版）

`bp-app-dev/` 内のファイルを編集し、`build.bat` で単一HTMLに結合できます。

```
bp-app-dev/
├── index.html   ← HTML構造
├── style.css    ← スタイル
├── db.js        ← データベース操作
├── chart.js     ← グラフ描画
├── csv.js       ← CSV入出力
└── app.js       ← メイン処理
```

```
build.bat を実行 → bp-app.html が生成される
```

## 主な機能

| 機能 | 説明 |
|------|------|
| 患者管理 | 電子カルテIDで管理。新規ID入力で即登録 |
| 血圧入力 | 日次の収縮期・拡張期を入力（Tab→Enter操作） |
| 折れ線グラフ | 月間の血圧推移を可視化（SBP=赤、DBP=青） |
| 月間サマリー | 平均・最高・最低を自動算出 |
| 高血圧警戒ライン | 収縮期140/拡張期90をグラフに表示 |
| CSV入出力 | データのエクスポート・インポート（USB転送向け） |
| JSONバックアップ | 全データのバックアップ・復元 |

## 操作方法

### 入力サイクル（Tabキー操作）

```
①測定日 [Tab] → ②収縮期 [Tab] → ③拡張期 [Tab] → ④メモ [Enter] → 登録完了
```

登録後、翌日の日付が自動入力され、収縮期欄にフォーカスが移動します。

### 患者切替

画面上部のセレクトボックスから患者を選択するか、トップ画面に戻ってIDを入力します。

### 月切替

`◀` / `▶` ボタンで前月・翌月を表示します。

## データ保存

- **IndexedDB**（ブラウザ組み込み）に保存
- USBメモリ上のCSVファイルでもバックアップ可能
- インターネット接続なしで全データがローカルに保持される

## CSVフォーマット

```csv
患者ID,患者氏名,測定日,収縮期,拡張期,平均血圧,メモ
12345,山田太郎,2026-01-15,135,85,102,朝食後
```

- 文字コード: UTF-8（BOM付き）
- Excelで開く場合、Shift_JISが必要な場合は要相談

## 技術情報

- **HTML5 + CSS3 + ES6 JavaScript**
- 外部ライブラリ不要（CDN非依存）
- `file://` プロトコルで動作
- IndexedDB: データベース名 `BloodPressureDB`

## 注意事項

- データはブラウザのIndexedDBに保存されます。ブラウザのキャッシュを消すとデータが失われる場合があります
- 定期的にCSVまたはJSONでバックアップを取ることを推奨します
- 本アプリは医療機器認証を受けていません。参考記録としてご利用ください
