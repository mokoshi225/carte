前版（v0.3）からの変更： ✖ 患者IDは自動採番 → ✔ 患者IDは手入力（電子カルテIDと統一）

1. プロジェクト概要

項目内容
アプリ名血圧モニター（仮称）
対象ユーザー医師・看護師（外来診療の日常業務）
動作環境
  • OS: Windows 10 / CPU: Intel Core i5-10500 / RAM: 8GB
  • ネットワーク: オフライン
  • 権限: 一般ユーザー（管理者権限なし）
  • データ転送: USBメモリ経由
実行方式ブラウザでローカルHTMLファイルを開く（file://）
技術制約CDN不可、インストール不可 → ブラウザ標準機能のみ（IndexedDB + Canvas 2D）

2. 機能要件

2.1 患者管理（IDベース・手入力方式）

設計方針：患者IDは電子カルテのIDと完全統一。新規登録時もIDを手入力する。

項目型規則備考
患者ID文字列/数値電子カルテのIDと一致（形式は自由、例: 12345, P001）必須・手入力
患者氏名文字列全角1〜20文字初回入力時のみ。以降は表示のみ
性別選択男 / 女任意、初回のみ入力
生年月日日付YYYY-MM-DD任意、初回のみ入力

2.2 キーボード操作仕様

全ての操作をマウス不要で完結できるよう設計する。

キー動作対象画面
Enter
  • ID入力中 → 該当患者のページに即座に遷移
  • 新規ID入力中 → 新規患者として登録して患者ページへ遷移
  • 血圧入力フォーム中 → データ登録（登録ボタンと同様）
全画面
Tab次のフォーム要素へフォーカス移動（Tab順序は論理的に設定）全画面
Shift+Tab前のフォーム要素へフォーカス移動全画面
Esc入力キャンセル / トップ画面に戻る患者ページ

Tab順序の具体例（患者ページ）

  1. ① 測定日（<input type="date">）
  2. ② 収縮期血圧（<input type="number">）
  3. ③ 拡張期血圧（<input type="number">）
  4. ④ メモ（<input type="text">）
  5. ⑤ Enterキーで「登録」（ボタンにフォーカス当たる必要なし）
💡 UXのポイント：
毎日数十人規模の外来で使うため、Tab→Tab→Tab→Enterの繰り返しで1件3秒以内に入力できるようにする。
登録後は自動的に次の日付（または次の未入力日）にフォーカスが移動する（オプション）。

2.3 血圧データ入力（日次）

入力項目型範囲備考
測定日日付YYYY-MM-DDデフォルトは本日
収縮期血圧（上）数値50〜300 mmHg必須
拡張期血圧（下）数値30〜200 mmHg必須
メモ文字列全角200文字以内任意

平均・最高・最低は月間サマリーで自動算出（日次入力不要）。

2.4 月間サマリー（自動算出）

各月の測定データから以下を自動算出・表示：

項目定義グラフ表示
平均収縮期月の全測定日のSBP平均値赤の水平点線 + 数値ラベル
平均拡張期月の全測定日のDBP平均値青の水平点線 + 数値ラベル
最高収縮期月の最大SBP（日付付き）赤の破線 + 値・日付ラベル
最低収縮期月の最小SBP（日付付き）薄い赤の破線 + 値・日付ラベル
最高拡張期月の最大DBP（日付付き）青の破線 + 値・日付ラベル
最低拡張期月の最小DBP（日付付き）薄い青の破線 + 値・日付ラベル

2.5 折れ線グラフ表示

表示項目内容
X軸日付（時系列）。月の全日数分のスペースを確保
Y軸血圧値（mmHg）。20mmHg刻みの目盛り
折れ線（日次データ）赤=収縮期 / 青=拡張期
平均線SBP/DBPそれぞれの月間平均を水平点線で表示
高血圧警戒ライン収縮期140mmHg（赤破線）/ 拡張期90mmHg（青破線）
高低値ライン月間最高・最低をそれぞれ水平線で表示
正常範囲帯SBP<120 かつ DBP<80 のエリアを薄緑で帯状着色
データポイント色分け正常:通常色 / 1期高血圧:オレンジ / 2期高血圧:赤枠
ツールチップマウスオーバーで日付・SBP・DBPを表示
凡例グラフ右上に色付き凡例 + 警戒ライン凡例

2.6 表示切替・フィルタ

機能内容
患者切替ID入力に戻る or 履歴ドロップダウンから選択
月単位ナビ◀前月 / ▶次月 ボタン + 年月表示
折れ線切替SBP / DBP / 平均線 / 警戒ライン の表示/非表示トグル
Y軸スケール自動調整 / 固定範囲手動指定

2.7 データ管理

機能内容ショートカット
ローカル保存IndexedDB（オフライン永続化）自動
CSVエクスポート患者 or 全患者の一括出力ボタン操作
CSVインポートCSVから一括取り込み（重複は日付で上書き確認）ボタン操作
JSONバックアップ/復元全データのエクスポート/インポートボタン操作
患者削除確認ダイアログ付きボタン操作

3.3 新規患者登録フロー

  ID入力欄に未登録のIDを入力 → Enter
    ↓
  「新規患者として登録しますか？」ダイアログ
    ↓
  患者情報入力（氏名・性別・生年月日・メモ）
    ↓
  [登録] → 患者ページへ遷移

4.2 IndexedDB スキーマ


■ Database: "BloodPressureDB" v1

○ patients（患者マスタ）
  keyPath: "id" (string) — 電子カルテIDと一致
  { id, name, gender, birthDate, memo, createdAt }

○ readings（測定データ）
  keyPath: "id" (auto-increment)
  インデックス:
    "byPatient"     → patientId
    "byPatientDate" → [patientId, date] (一意制約)
    "byDate"        → date
  { id, patientId, date, systolic, diastolic, note, createdAt, updatedAt }
